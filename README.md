# BookOrGo

Static travel website for https://bookorgo.com.

Upload the contents of this directory to the hosting document root. Entry page: index.html. There is no build step. Enable HTTPS and verify support@bookorgo.com delivery before submitting an affiliate application.

Includes 8 Dubai guides, policies, copyright/takedown page, favicon, responsive image sources and language/currency preferences. No supplier API or payment integration is included.
